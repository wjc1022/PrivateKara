# 视频全屏与方向

[English](VIDEO_FULLSCREEN.md) | 简体中文

对应 #6，基于已合入 main 的 #7 布局。播放器请求 **HTML 容器全屏并保留当前方向**，以 `document.fullscreenElement` 确认进入；请求 Promise 成功本身不等于已经全屏。API 缺失或拒绝时保留直立页面铺满，按钮明确显示“退出页面铺满”。页面铺满无法隐藏浏览器工具栏。

不通过 UA、型号、屏幕宽度猜测手机或平板。浏览器没有可靠的设备类别能力信号，因此所有设备默认保留当前方向：竖屏平板可以正常全屏，不会被强制转横屏。手机需要横屏时可手动横放；仅在确认原生全屏、当前视口为竖屏且存在锁定 API 时，显示“尝试横屏”（可能位于“更多”内）。用户明确点击后才请求一次 `screen.orientation.lock('landscape')`。真实横屏视口不重复请求。成功后可用“跟随设备”释放本次锁定；失败／缺失显示手动旋转提示，不自动重试，也不在页面铺满模式尝试锁定。无法可靠判断设备类别意味着普通全屏点击不会自动强制手机横屏，这是保留竖屏平板体验的明确取舍。

物理设备方向、浏览器视口尺寸、原生全屏、锁定 API 结果、CSS 变换和 AirPlay 输出分别看待。锁定 Promise 成功不是视口／外接屏幕已经旋转的证明；布局只跟随实际内容宽度。所有模式保留 656px 分栏阈值、18px 固定字号、物理右侧歌词、无堆叠／叠加和 `object-fit: contain`。已删除 CSS 90 度旋转及交换 dvw／dvh 的回退，不使用原生视频全屏替代 HTML 歌词。没有电视渲染、外接屏幕检测或 AirPlay 接收端 API。所有平台均获得包含 Safari／iOS 控制中心操作的本地化提示；安装模式保持竖屏时可尝试 Safari。manifest 使用 `orientation: any`，系统仍可能限制方向。

关闭、切歌（包括视频切视频）、原生全屏退出、导航、页面离开及进入后台均取消待完成请求。只有应用成功取得本次锁定后才调用 unlock；失败／不支持／仅进入全屏不会解除其他方向状态。待完成的锁定成功后若会话已取消，立即释放它。进入／退出及锁定操作串行处理；浏览器拒绝退出时保留真实原生状态，可重试或使用浏览器控件。所有模式使用水平触摸定位。

## 证据边界

Node 控制器测试模拟原生 API，覆盖默认不锁定、显式请求、成功／缺失／拒绝、锁定所有权、手动视口变化、原生退出、关闭／重开、迟到请求和退出失败。Chromium 检查真实页面铺满几何、水平触摸定位、三语言提示及 #7 布局，并通过明确标记的模拟原生 API 检查原生状态与操作按钮。基础检查包含音频、歌词同步、存储和离线缓存。模拟原生状态／锁定和桌面浏览器不能证明移动端原生旋转或 AirPlay；浏览器输出静音，不能证明实际声音输出。

平台资料（并非设备验证）：[WebKit Safari 16.4](https://webkit.org/blog/13966/webkit-features-in-safari-16-4/) 描述 macOS／iPadOS 容器全屏及初步方向 API，不能据此推断所有 iPhone 均支持；[方向锁定文档](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock) 标注支持有限，并说明可能要求移动端全屏，因此必须处理能力缺失和请求失败。

## 实机检查清单——全部待验证

每项记录设备型号、系统版本、Safari／安装模式、方向锁定设置、接收器／电视型号及提交版本。使用 HTTPS，保留原始媒体和备份，分别准备含逐字 LRC 和无歌词的 MV。

1. **iPad Safari 与安装后 PWA：**从竖屏进入全屏应保留竖屏；从横屏进入不得多转 90 度。足够宽时保持右侧分栏；656px 附近分屏时仅按内容宽度切换歌词。按钮／浏览器退出并重复三次，检查固定 18px 字号、无重叠、安全区域、更多／队列及触摸定位。
2. **真实 iPhone Safari + AirPlay 屏幕镜像：**通过控制中心启动屏幕镜像（区别于仅视频 AirPlay）。分别开启／关闭方向锁定，从竖屏进入；记录原生全屏或页面铺满。若原生全屏提供“尝试横屏”，点击并记录 API 结果和真实视口方向；测试“跟随设备”。不可用／失败时手动横放，确认玩家保持直立可操作。直接观察外接屏幕视频、控件和歌词方向，不能仅凭手机显示判断成功。
3. 从横屏进入、退出、回到竖屏、重复进入至少三次。确认没有侧转界面、残留锁定或无法操作的控件。在手机与外接屏幕检查 25%／75% 触摸定位、字幕开关及歌词同步。
4. 铺满时切换 MV、切到音频、关闭／重开、导航、进入后台／返回、断开／重新连接镜像。确认状态清理及后台播放返回后需手动恢复。安装后 PWA 重复测试；方向仍受限时尝试 Safari，并记录差异。
5. 单独检查实际可听输出、接收端延迟及持续播放。桌面通过、时间推进、API Promise 成功都不能替代这些结果。外接屏幕仍侧转属于实机检查失败，需继续调查，不能算作回退成功。
